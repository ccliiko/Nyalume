Key 与陪伴记忆

通过阿里云百炼中国内地（北京地域）接入千问，使用该地域的百炼 API Key。 默认使用千问 Plus；可选择其他千问模型，调用额度按你的百炼账号计费。 Key 默认只留在页面内存中；发消息时经后端转发给你选择的服务商，不写入服务器数据库或日志。勾选后会明文保存在此浏览器的站点存储中，退出账号时清除。 这些记忆保存在你的账号中，可以随时修改或清空；每次聊天会一起发送给你选择的服务商。历史默认带入最近 20 条，并受上下文字数预算限制。冒险另带累积摘要与背包。
