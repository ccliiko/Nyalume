Nyalume v0.5.3 Windows 便携版
======================

开始使用
1. 解压整个 Nyalume 文件夹；两个 EXE 共用 _internal 和 unity 目录，不能单独搬走。
2. 双击 Nyalume3D.exe，默认打开 Unity Eku；双击 Nyalume2D.exe，打开原有 2D 桌宠。
   两种模式请分别启动，先退出当前桌宠再打开另一个。点击桌宠可打开聊天窗口。
   需要在管理员权限的游戏中互动时，使用 启动3D桌宠-管理员.cmd。
3. 首次使用时，在设置中填写自己的 API 服务商、API Key 和模型。
   更新时点击聊天窗口侧栏「版本更新」，发现新版后点击「下载并安装最新版」。
   下载时保持桌宠运行；准备完成后退出桌宠并关闭聊天窗口，更新器自动安装并重启。
   配置、聊天记录和自备模型保留；失败时尝试恢复原程序，备份在安装目录旁 .nyalume-update-* 内。
   默认自动加速：版本查询失败时使用 GH-Proxy，下载优先加速、失败回退 GitHub。
   可在更新页保存「GitHub 直连」或自定义 HTTPS 镜像前缀；自定义源须同时支持 API 和下载链接。
   加速服务由第三方提供，只接收公开发行请求；SHA-256 核对下载与发行信息是否一致。
4. 3D 桌宠右键菜单可切换至附带的野餐式 MikuQ，借物署名见借物表.md。
   也可把自备的 PMX/VRM 模型放进 models\（每个模型一个子目录），PMX 使用的 VMD
   动作放进 motions\，双击即用，不需要在界面里选目录。
   完整步骤见 3D桌宠说明.md。

v0.5.3 修复
- 文件撤销区分新文件、空文本和不可恢复的旧快照，避免误删；旧数据库自动补充快照状态。
  恢复内容按 UTF-8 写回，不恢复原编码或文件元数据，也不检测外部编辑冲突。
- 模型截断、过滤或缺少标准结束信息时保留可见片段并报错，不作为完整回答存档或推进记忆。
  不新增自动续写或额外重试；非标准结束协议的接口可能需要服务商适配。
- 生成中的会话须先停止再删除，避免晚到回复重新建立已删除记录。
- 分清 Unity Eku 和 PMX 的鼠标操作说明；角色、动作与材质保持 v0.5.2 的版本。

v0.5.2 功能继续保留
- 连续摸头支持折耳、回弹、笑眼和轻微张口；温柔划动逐渐放松，松手平滑恢复。
- 柔和捏脸支持左右独立按压、拖动和恢复；视线与情绪随互动变化。
- 版本更新页显示 GitHub 版本、检查时间及下载进度，更新源收进网络设置。
- 默认采用无语音播放器；不包含 Peek、微风待机及全身／姿态生活试作。
- 恢复自主行为试作的明亮外观，移除旧桌面实验灯光覆盖。

v0.5.1 功能继续保留
- Eku 右键「换装」可切换私服与黑色 Asteria Lycee 制服，分别设置衣物穿脱。
  两套状态独立记忆，重启恢复上次选择；「恢复默认」穿回完整私服，基础内衣内裤始终保留。
- 3D 桌宠右键「放大镜」可开启 3× 局部查看；点「移动框选」选择观察部位，
  点「完成框选」或按 Esc 后平滑跟随。查看窗可拖动位置，也可移到其他显示器。
  放大镜保留当前材质与灯光，主桌宠大小不变，打开右键菜单时继续显示。

说明
- 适用于 Windows 10/11 x64，聊天窗口依赖系统 WebView2（多数系统已内置）。
- 这是本地版：目前没有登录、云同步和打赏功能。
- 会话、记忆、壁纸与 API 配置仅保存在这个便携目录内。
- API Key 不随安装包分发，但当前会明文保存在本机 .env；请勿共享填过密钥的程序目录或备份。
- 移动或备份时，请保留整个 Nyalume 文件夹。
- 默认包含原有 2D 角色的待机、互动和表情帧。
  打包时可用 -PersonalAssets:$false 显式排除，输出带 no-2d 后缀的无 2D 素材包。
- 野餐式 MikuQ 以注明作者的二次配布方式附带，不加密；保留原始模型、贴图与 README。
  构建时可用 -BundleMikuQ:$false 排除。此选项与 2D 素材、-WithModels 分别控制。
- 内置 Eku 使用加密 Unity 资源，保留当前材质、表情、物理和动作；许可见 unity\Eku-LICENSE-ja.pdf。
  加密提高提取门槛，不代表无法逆向。其他自行导入的模型继续使用现有 PMX/VRM 加载方式。
- 2D 启动时短暂淡入，操作即可结束；3D 启动时逐笔雕刻出角色图标，配有随机猫娘台词。
  按 Esc 或点击“隐藏动画”可收起启动窗口，模型继续加载。完整更新记录见 CHANGELOG.md。

许可、隐私与素材
- 下载、安装或使用即表示接受 EULA.md。
- 隐私与数据处理见 PRIVACY.md。
- 第三方组件、外部服务，以及 3D 模型/动作的再分发与展示条件，见 THIRD_PARTY_NOTICES.md。
  默认包附带加密的 Unity Eku，以及按随附 README 署名的野餐式 MikuQ；不自动附带其他第三方 PMX/VMD。
  若目录中没有该模型及借物表，则使用者需自行导入模型。素材来源的内部记录不随包分发。

如果 Windows 首次运行时显示安全提示，请核对文件来源后再决定是否继续。
