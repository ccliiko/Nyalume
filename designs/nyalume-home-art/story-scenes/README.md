## 工作流与技巧

- 直接读取本机用户的 `double_lora_BA.json` 连接图，保留 StarSea pastel v5、z3 0.4、鬼针草 0.65，以及脸部和手部细化链。用户原文件不修改；副本与 SHA-256 随生成记录保存。
- 主采样保留用户原来的 30 steps、dpmpp_2m / karras；首轮 CFG 8，后续日常稿降为 5.5，缓解强烈色调和高光。分辨率按场景调整。每次候选保留独立 seed 和 API JSON，不覆盖失败或旧候选。
- 动作、构图放在正向前部，然后是角色、服装、环境。避免同时要求多个矛盾机位、多个时间点或大块广告留白。
- 手部细化保留持物与场景上下文。脸部 denoise 0.28、手部 0.26 是本轮保留动作的试验参数，并非通用最优值。根据 [Impact Pack 官方说明](https://github.com/ltdrdata/ComfyUI-extension-tutorials/blob/Main/ComfyUI-Impact-Pack/tutorial/detailers.md)，Detailer 对检测区域放大再采样，较大 crop 可能显著增大内部尺寸，羽化也不保证改善边缘；本轮保持有限 crop，并逐图检查。
- 动作、服装标签从 [AI 绘画提示词超市](https://github.com/BFRKQSB7/ai-prompt-supermarket) 中筛选，见 `selected-tags.json`；与短句配合描述持物、动作关系和构图。
- PNG 保留 ComfyUI 原始输出和 prompt 元数据；WebP 为质量 93 的查看副本，不额外像素化、不裁掉重复人物。

`shots.json` 保存创作方案；`generate.py submit dessert star` 可生成指定场景；`generate.py collect` 收取已完成结果。`jobs.json` 保存 prompt ID，`场景-seed.json` 保存实际提交图。ComfyUI 原始解码图另存在输出目录的 `base_` 文件，用于对照细化前后。

## 配色修订

用户指出首张蓝色占比过大后，尝试暖色又出现整体偏黄。最终日常稿采用中性光照、颜色绑定到具体物件，并降低 CFG；不再在负向中逐个排除蓝色或紫色，以避免新的单色偏移。星术师候选 9274302 已通过目视检查，保留其象牙白、暗梅紫与金色的方案。

## 动作修订与交付记录

每日卡片的初稿像正面摆拍信封，用户明确表示不喜欢。该版本已从 selected 移到 rejected-by-user；新方案改为她在打开的书页间放压花草莓书签，听见你靠近后自然回头。出发稿使用本机已有 OpenPose 对身体姿态加约束，原双 LoRA 与脸手细化链仍保留。所有控制节点与强度记录在候选 API JSON 中。

`selected/` 是选定素材；其内每张 PNG 对应同名精确 API JSON，`manifest.json` 记录采用的 seed、尺寸与 CFG。创作方案中的细节可能在生成过程中调整，复现交付图应使用 selected 内的 JSON。
