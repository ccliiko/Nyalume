# Nyalume 0.2.0 Windows 便携版与 3D 桌宠教程

## 1. 解压与首次启动

适用 Windows 10/11 x64。解压整个 `Nyalume-v0.2.0-windows-x64` 文件夹，保留 `Nyalume.exe`、`_internal` 和随附文档；不要只复制 EXE。双击 `Nyalume.exe` 启动 2D 桌宠，点击桌宠打开聊天窗口。在聊天窗口设置中选择 API 服务商、填写自己的 API Key 和模型。没有 API Key 时仍可查看界面与使用本地桌宠，但 AI 对话和主动搭话不可用。

程序使用系统 WebView2 运行聊天窗口和 3D 画面。若窗口无法打开，请先安装或修复 Microsoft Edge WebView2 Runtime。API Key、会话与配置是本机数据，**不要把已填过密钥的程序目录或备份分享给别人**。移动或备份时保留整个文件夹。

`-personal` 后缀的包仅供制作者本机使用，可能带有尚未取得商业发行许可的 2D 角色帧；不得把该包直接上传为公开下载、付费版本或宣传素材。

## 2. 启动 3D 桌宠

3D 运行代码与 Three.js 已随 EXE 打包，第三方 PMX 模型和 VMD 舞蹈**没有随包附带**。先从作者原发布处取得允许你使用的 `.pmx` 模型及其贴图，保持原目录结构。

1. 双击 `启动3D桌宠.vbs`，在弹出的输入框中填写模型文件夹或 `.pmx` 文件的完整路径；也可以把模型文件夹拖到该文件上。这个入口不会打开控制台，也不会请求管理员权限。
2. 若你确实需要在带反作弊或高完整性进程的游戏前台互动，可在 PowerShell 中用下文命令并追加 `--admin`，Windows 会弹出 UAC。普通桌面使用无需管理员权限。
3. 要指定自己的 VMD 动作目录，可从 PowerShell 运行：

   ```powershell
   .\Nyalume.exe --pet3d --model "D:\模型\我的角色" --vmd "D:\动作目录"
   ```

   管理员模式在 `--pet3d` 后加 `--admin`。模型和动作目录只是示例，请换成你已合法取得的本机路径。目录内多个模型可以用桌宠右键菜单切换；它通过重启 3D 窗口完成加载。

4. 不指定 `--vmd` 时使用随程序提供的自然站姿待机。模型、动作的骨骼和表情名称可能不一致；某些舞蹈会穿模、缺表情或动作幅度异常，这是素材兼容性问题。

## 3. 3D 操作与聊天

左键单击模型的不同部位触发表情反馈；按住左键拖动可拖拽桌宠；右键轻点打开菜单，按住右键左右拖动可旋转；滚轮缩放；双击切下一支舞；中键退出。菜单可选择动作、模型、风格、聊天窗口、主动搭话档位及手动安静模式。手动安静只随用户调整，重启后保留。

在 Nyalume 聊天窗口中可以说“看看桌宠现在的状态”“让桌宠跳 IRIS OUT”“让桌宠开心一下”或“让桌宠回到待机”。Agent 会调用 `pet_status` 和 `pet_perform` 读取状态并指挥正在运行的 3D 桌宠；如果该舞蹈未在你的动作目录中，会如实报错。状态工具只传模型、心情、动作和安静状态，不传前台窗口标题或媒体标题。普通对话仍走现有聊天能力。

3D 桌宠的主动搭话需要先在聊天设置中配置 API Key，并在保存设置后重启 3D 桌宠。两者共用 `_internal/.env` 中的 `LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL`。菜单提供安静、寡言、正常、健谈、话痨五档；手动安静开启时不会主动打扰。若允许主动搭话读取正在播放的媒体标题，该标题可能随提示词发送给你配置的模型服务商。

## 4. 文件、日志与排查

| 文件或位置 | 用途 |
| --- | --- |
| `Nyalume.exe` | 2D 桌宠与聊天入口；`--pet3d` 启动同一程序中的 3D 前端 |
| `_internal/` | Python 运行时、网页资源、Three.js 和自制待机动作；不要单独移动 |
| `VERSION.txt` | 本地构建的版本号 |
| `_internal/.env` | 从聊天设置保存的 API 配置；含密钥，切勿分享 |
| `%USERPROFILE%\.nyalume\pet3d_settings.json` | 3D 风格、安静和主动搭话偏好 |
| `%TEMP%\nyalume_pet3d.log` | 3D 关键事件与错误线索 |
| `%TEMP%\nyalume_pet3d_drag.log` | 仅调试模式下的帧与输入细节 |
| `pet_error.log` | 主桌宠启动失败时的 Python 错误信息 |

- 3D 窗口空白：确认 `.pmx` 与贴图在原有相对路径，检查关键日志；若某模型不行，先换另一合法模型验证。
- 菜单点击偏位或画面周期性停顿：确认使用的是 0.2.0 整套目录，退出旧 3D 进程后再启动；把发生时间和日志片段保留下来。
- 游戏中点不到桌宠：先试无边框窗口模式；必要时用管理员启动脚本。独占全屏的覆盖受 Windows 限制。
- 聊天窗口打不开：检查 WebView2 Runtime 和本机 8000 端口是否被占用。
- 升级前备份自己的配置、会话和模型路径。不要覆盖或分享包含 API Key 的 `.env`。
