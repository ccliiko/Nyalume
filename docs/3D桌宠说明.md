# Nyalume 3D 桌宠说明

> 解压、首次启动、模型/动作放哪儿、怎么摸她、右键菜单每个开关是什么意思。
> 程序许可见 `LICENSE` / `EULA.md`，隐私见 `PRIVACY.md`，
> 第三方组件与 3D 素材的再分发边界见 `THIRD_PARTY_NOTICES.md`。

## 一、解压与首次启动

适用 Windows 10/11 x64。解压**整个** `Nyalume-v0.3.2-windows-x64` 文件夹，保留 `Nyalume.exe`、
`_internal` 和随附文档；不要只复制 EXE。双击 `Nyalume.exe` 启动 2D 桌宠，点击桌宠打开聊天窗口，
在聊天窗口设置里选择 API 服务商、填写自己的 API Key 和模型。没有 API Key 时界面和本地桌宠仍可用，
但 AI 对话和主动搭话不可用。

程序用系统 WebView2 运行聊天窗口和 3D 画面；窗口打不开就先安装或修复 Microsoft Edge WebView2 Runtime。
API Key、会话与配置都在本机，**不要把填过密钥的程序目录或备份分享给别人**；移动或备份时保留整个文件夹。

`-personal` 后缀的包仅供制作者本机使用，可能带有尚未取得商业发行许可的 2D 角色帧，
不得直接上传为公开下载、付费版本或宣传素材。

## 二、启动 3D 桌宠

3D 运行代码与 Three.js 已随 EXE 打包，第三方 PMX 模型和 VMD 舞蹈**不随包附带**。模型和动作放
**程序目录下的两个固定文件夹**，双击启动脚本即用，界面上没有选目录的步骤：

```text
Nyalume\
├── Nyalume.exe
├── models\          模型：每个模型一个子目录（models\锁瞑\xxx.pmx），也可以直接放 .pmx
└── motions\         动作：.vmd 直接放里面，子目录会被递归找
```

| 启动方式 | 用途 |
| --- | --- |
| `启动3D桌宠.cmd` | **直接双击**：用 `models\` 里的第一个模型 + `motions\` 里的全部动作 |
| `启动3D桌宠-管理员.cmd` | 同上，但提权启动。反作弊游戏（原神/鸣潮/绝区零那类）是高完整性进程，不提权收不到鼠标，游戏内互动无效；普通桌面使用不需要管理员权限 |

`models\` 是空的会弹提示窗告诉你该放哪儿。想临时指到别处（不放进那两个目录）：
`启动3D桌宠.cmd "D:\模型\某角色"`（第二个参数可以给动作目录），或者直接
`Nyalume.exe --pet3d --model <目录或 .pmx> [--vmd <动作目录>]`，管理员模式在 `--pet3d` 后加 `--admin`。
模型和动作目录只是示例，请换成你已合法取得的本机路径。

同一时间只跑一个桌宠：重复启动会被忽略（两个实例会抢同一个鼠标）。想换角色就在右键菜单里"换模型"，
那是重启式的（3–5 秒）。不指定 `--vmd` 时用随程序提供的自然站姿待机；
模型、动作的骨骼和表情名称可能不一致，某些舞蹈会穿模、缺表情或动作幅度异常，这是素材兼容性问题。

## 三、鼠标怎么操作

| 操作 | 效果 |
| --- | --- |
| 左键单击她 | 按部位反应：头 / 脸 / 胸 / 腹 / 手 / 裙 / 披风 / 腿，随机表情 + 飘一个符号 |
| 左键按住拖 | 抓住局部拖动：头发、马尾、衣袖、裙摆、手、手臂、腿等，松手带一点回弹 |
| 左键双击 | 切到动作库里的**下一支舞** |
| 右键单击她 | 打开菜单（菜单画在画面里；点透明处不算） |
| **右键按住拖** | **左右旋转她**，松手带惯性；拖动距离超过几像素就不会弹出菜单 |
| 滚轮（在她身上） | 放大 / 缩小，以光标为中心 |
| 中键单击她 | 退出桌宠（怕误触就用菜单里的"退出"） |
| 光标靠近她 | 视线跟随：眼睛 + 脖子 + 头一起转；只在**她身体附近**（轮廓外扩 25%）才跟，走远自动回正视 |
| 双击（透明处） | 无反应——她只在自己的像素上吃点击，别的地方点得到下面的窗口 |

两个有意为之的取舍：全局鼠标钩子**从不吞输入**（在她身上滚滚轮，底下的窗口也会跟着滚；
换来的是绝不会出现"整台电脑鼠标键盘失灵"）；她也不会自动抢/还前台焦点。

## 四、右键菜单

| 菜单项 | 说明 |
| --- | --- |
| 打开聊天窗口 | 打开主程序的聊天窗，**她继续留在桌面上**（两个窗口并存；关掉她时这个聊天窗也会跟着关）。双击她不是聊天，是切"下一支舞" |
| 动作 ▸ | 列出动作目录里所有 `.vmd`（`▶` 是当前这支），最后一项"回到待机" |
| 换模型 ▸ | 同一个父目录下所有含 `.pmx` 的模型；标 `●` 的是当前 |
| 换风格 | 光照 × 滤镜 5 档组合，见下表。箭头在行的两头：点行**左半边**往左切、**右半边**往右切，点完菜单不关，方便连点 |
| 全屏游戏自动降帧：开/关 | 检测到全屏游戏时把推帧降到 30，把资源让给游戏（默认开） |
| 手动安静：开/关 | 只随你调，不会自动失效；开会/机器忙时还会自动安静（另算） |
| 主动搭话 ▸ | 安静 / 寡言 / 正常 / 健谈 / 话痨（需要主程序配了 `LLM_API_KEY`） |
| 配置目录 ▸ | 导入模型（选 .pmx 文件）/ 导入动作（选 .vmd 文件）、脚部 IK：开/关，以及打开动作目录 / 模型目录 / 状态与配置目录。模型和动作的**位置是固定的**（`models\` / `motions\`），所以没有选文件夹的入口 |
| 退出 | 关掉她（同中键） |

风格档（"换风格"循环切换）：

| 档 | 光照 | 滤镜 |
| --- | --- | --- |
| 柔和·浓郁 | 环境光 0.6、主光 1.0、无轮廓光 | contrast 1.22 / saturate 1.45 |
| 游戏味·鲜明 | 环境光 0.35、主光 1.25、轮廓光 0.9 | contrast 1.12 / saturate 1.28 |
| **游戏味·浓郁（默认）** | 同上 | contrast 1.22 / saturate 1.45 |
| 柔和·鲜明 | 柔和光照 | 鲜明滤镜 |
| 原版·无滤镜 | 环境光 1.0、平光 | 关 |

环境光是"加法"的白光，给多了颜色会被洗淡；要对比和颜色就选"游戏味"两档。

## 五、放模型和动作

- **放哪儿**：模型丢 `models\`、动作丢 `motions\`，重启桌宠就能看到（换模型/动作库必须重启）。
- **模型**：`--model` 可以传目录，也可以传具体 `.pmx`。目录里混着武器/道具没关系：
  程序会先踢掉道具（武器/手杖/锤子/手机/喇叭/泡泡/葡萄/书/杖），再挑名字里带角色名的主模型；
  同名多个取排序第一个（火花的"（修）"和"（修2）"里会取"修2"）。
- **动作**：`--vmd` 传目录时会递归找 `.vmd`；纯相机文件（没有骨骼帧）自动跳过。
  自带 `motions/idle.vmd` 是项目自制的自然站姿待机动作，不带任何第三方素材。
- 双击她 = 跳到动作库里的下一支；菜单"动作 ▸"里可以点具体的某支。
- 菜单里的"换模型"是**重启式**的（3–5 秒）。往 `models\` / `motions\` 里新加的文件
  也要重启一次才会出现在菜单里。

## 六、她会自己做什么

- 待机循环播 `idle.vmd`：呼吸、重心微摆、手指自然弯曲、脚尖略外八。
- 没人理她 18–48 秒会自己做个小动作并飘个符号（♥ ！ ？ ♪ …）。
- 开会（前台窗口判定为会议）或 CPU 长时间 ≥85% 时自动安静；全屏游戏时自动降帧。
- 配了 `LLM_API_KEY` 才会"主动搭话"：按档位随机间隔（话痨 3–8 分、健谈 10–20 分、
  正常 20–40 分、寡言 45–75 分，安静 = 不主动），**夜里也照常说**；
  刚被碰过 3 分钟内不说，连续两次被无视会静默一小时，人不在超过 15 分钟时部分提议不发。

## 七、和聊天窗口 / Agent 一起用

在 Nyalume 聊天窗口里可以说"看看桌宠现在的状态""让桌宠跳 IRIS OUT""让桌宠开心一下"或
"让桌宠回到待机"。Agent 会调用 `pet_status` 和 `pet_perform` 读取状态并指挥正在运行的 3D 桌宠；
舞蹈不在你的动作目录里会如实报错。状态工具只传模型、心情、动作和安静状态，不传前台窗口标题或媒体标题。

主动搭话需要先在聊天设置里配置 API Key，并在保存设置后重启 3D 桌宠；两者共用 `_internal/.env` 里的
`LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL`。若允许主动搭话读取正在播放的媒体标题，
该标题可能随提示词发送给你配置的模型服务商。

本地回环接口（端口见 `pet3d_endpoint.json`），方便脚本和 Agent 用：

- `GET /pet_state` → 当前模型、动作、心情体力、桌面分类、帧率
- `POST /pet` → `{"action": "dance", "name": "IRIS OUT"}` / `idle` / `say` / `face` /
  `look`（x,y 归一化）/ `style` / `model` / `quiet` / `talk_mode` / `react`（部位）

## 八、文件、日志与排查

| 文件或位置 | 用途 |
| --- | --- |
| `Nyalume.exe` | 2D 桌宠与聊天入口；`--pet3d` 启动同一程序里的 3D 前端 |
| `_internal/` | Python 运行时、网页资源、Three.js 和自制待机动作；不要单独移动 |
| `models/` | 3D 桌宠的模型目录：每个模型一个子目录；换模型/加模型都放这里 |
| `motions/` | 3D 桌宠的动作目录：`.vmd` 放这里，子目录会被递归查找 |
| `VERSION.txt` | 本地构建的版本号 |
| `_internal/.env` | 从聊天设置保存的 API 配置；含密钥，切勿分享 |
| `%USERPROFILE%\.nyalume\pet3d_settings.json` | 3D 风格、自动降帧、搭话档位、手动安静 |
| `%USERPROFILE%\.nyalume\pet3d_state.json` | 心情与体力 |
| `%USERPROFILE%\.nyalume\pet3d_endpoint.json` | 本地接口端口 |
| `%TEMP%\nyalume_pet3d.log` | 3D 关键事件与错误线索 |
| `%TEMP%\nyalume_pet3d_drag.log` | 仅调试模式下的帧与输入细节 |
| `pet_error.log` | 主桌宠启动失败时的 Python 错误信息 |

- **她不见了 / 打不开**：先看任务管理器有没有 `Nyalume.exe`（或开发版的 `pythonw.exe`），
  有就结束掉再启动——重复启动会被单实例锁挡掉，看起来像"打不开"。
  缩放窗口、切全屏之后如果窗口被系统收走，程序会自己重建（2 秒内回来）。
- **卡顿**：待机约 58fps、跳舞约 55–59fps（`gap_p95` 约 20ms）属正常；
  跳舞的"台阶感"多来自舞蹈文件本身是 30fps 关键帧。
- **灰 / 塑料感**：先确认风格档（见上表）；另外各模型自带材质差异很大，
  程序会把明显偏灰的整套材质拉回常用档。
- **点她没反应**：游戏里要点中需要管理员模式；另外她只在自己的像素上吃点击。
- **3D 窗口空白**：确认 `.pmx` 与贴图在原有相对路径；若某个模型不行，先换另一个合法模型验证。
- **菜单点击偏位或画面周期性停顿**：确认用的是 0.3.2 整套目录，退出旧 3D 进程后再启动。
- **游戏中点不到她**：先试无边框窗口模式；必要时用管理员启动脚本（独占全屏的覆盖受 Windows 限制）。
- **聊天窗口打不开**：检查 WebView2 Runtime 和本机 8000 端口是否被占用。
- 升级前备份自己的配置、会话和模型路径；不要覆盖或分享含 API Key 的 `.env`。

## 九、给开发者

- 画面探针（开发用）：`viewer.html?...&probe=6000` 报布料抖动与是否持续下沉；
  `&look=3500` 报渲染后画面的饱和度/亮度/对比度；结果写进页面标题。
  控制台里也可以 `await window.__probeJitter(3000)`。
- 重新生成待机动作：`python tools/make_idle_vmd.py`
- 量模型的朝向/尺寸/材质：`python tools/pmx_probe.py "xxx.pmx"`
- 打包：`powershell -File packaging/build_windows.ps1 -Version 0.3.2 -PersonalAssets [-WithModels]`
  （`-WithModels` 把本机 `模型\` 里的模型打进包的 `models\`；动作按 `-MotionPick` 白名单
  打进 `motions\`，默认只带 IRIS OUT、だいあるのーと、Stay Tonight 三支——`动作配布`
  里混着 `.blend`/`.blend1` 工程文件，整个拷进来会白多 600 MB。
  要全带：`-MotionPick @()` 或 `-MotionPick @("某个目录名")`）
